# 夕張・SCL 地域内集計（再現用）

年次比較の各シーンについて、南側・北側の概略範囲内の SCL（Scene Classification Layer, 20 m）を集計した結果と、その再現手順。

- 結果: [`yubari-scl-region-stats.json`](yubari-scl-region-stats.json)（2026-10-03 取得）
- 再現: リポジトリ直下で

```bash
node --experimental-strip-types scripts/scl-region-stats.mjs both > docs/analysis/yubari-scl-region-stats.json
# 日付や地域を指定する場合
node --experimental-strip-types scripts/scl-region-stats.mjs south 2019-09-30 2021-10-09
```

## 定義（アプリと共通: `src/lib/scl.ts`, `src/lib/cog.ts` の `sampleGrid`）

- 範囲: 公開地名を基にした概略 bbox（南側 141.975,42.91,142.09,42.98 ／ 北側 141.915,42.975,142.055,43.065）。**林班・入林可能範囲ではない**。個人の地図・入林情報は使っていない。
- 格子: bbox を 150×150 のセル中心でサンプリングし、SCL のフル解像度（20 m）に**最近傍**で対応付け。
- 分母: 全格子点（22,500）。画像範囲外(255)・SCL=0 も含む。
- 無効（除外）クラス: 0 欠測, 1 飽和/欠陥, 3 雲影, 8・9 雲, 10 巻雲, 11 雪。暗域(2)・未分類(7)は有効のまま別枠で数える。
- `sceneCloudCover` は STAC の `eo:cloud_cover`（**シーン全体**）。地域内の割合とは別。
